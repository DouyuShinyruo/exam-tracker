# 考证倒计时小程序 - 设计文档

## 概述

一款微信小程序，帮助用户追踪各类证书考试的报名时间和考试日期，通过倒计时展示让用户不会错过重要时间节点。

## MVP 目标

快速上线一个可用的版本：手动录入考试信息，首页展示倒计时列表，数据保存在本地。

## 核心功能

### 1. 考试管理

**添加考试（两种方式）：**
- **从预设目录选择**：搜索常见考试名称（如"司法考试""软考""教资"），选中后自动填充基本信息（名称、考试周期），用户只需补充日期和地区
- **自定义添加**：手动填写证书名称、考试日期（支持精确日期或大致月份）、报名截止日期（可选）、所在地区

**预设考试目录（内置数据）：**
- 包含国内常见证书考试（软考、教资、司法考试、CPA、一建、消防工程师等）
- 每条预设记录包含：考试名称、考试类别、通常考试月份（参考值）、官方网址
- MVP 阶段内置约 30-50 个常见考试，数据写死在代码中
- 后续可通过后端接口动态更新目录

**编辑/删除：**
- 编辑考试：修改已有考试的所有字段
- 删除考试：左滑或长按删除，需二次确认

### 2. 首页展示

- **考试卡片列表**：按考试日期排序（最近的在前）
- **倒计时显示**：精确日期显示"距离考试还有 X 天"，大致月份显示"预计还有约 X 个月"
- **状态标签**（优先级从高到低，同时满足多个条件时取最高优先级）：
  - 考试临近（红色）：距考试 <= 7 天（最高优先级）
  - 即将截止（黄色）：距报名截止 <= 7 天且当前日期 < 报名截止日期
  - 报名中（绿色）：当前日期 < 报名截止日期
  - 已截止（灰色）：当前日期 > 报名截止日期且距考试 > 7 天
- **筛选**：全部 / 报名中（含即将截止）/ 考试临近

### 3. 数据存储

- MVP 阶段使用小程序本地存储 `wx.setStorageSync`
- 数据格式：JSON 数组，每条记录包含 id、名称、考试日期、报名截止日期、地区、创建时间

## 技术方案

### 技术栈

- 微信小程序原生框架
- WXML + WXSS + JavaScript
- 微信开发者工具

### 数据模型

**预设考试目录（preset-exams.js，内置数据）：**
```javascript
{
  id: "preset_001",
  name: "软件设计师",
  category: "计算机",            // 类别：计算机、法律、财会、建筑、医学、教资 等
  examMonths: [5, 11],          // 通常考试月份（参考值）
  officialUrl: "https://www.ruankao.org.cn",
  description: "全国计算机技术与软件专业技术资格（水平）考试"
}
```

**用户考试记录（user-exams，本地存储）：**
```javascript
{
  id: "exam_1683456789",
  presetId: "preset_001",       // 关联预设目录 ID，自定义添加时为 null
  name: "软件设计师",
  examDate: "2026-11-07",       // 精确日期或月份末尾补01
  examDateType: "exact",        // "exact" | "approximate"
  registrationDeadline: "2026-09-15", // 可选
  region: "北京市",
  source: "manual",             // "manual" | "crawler" | "official"
  sourceUrl: null,
  lastSyncAt: null,
  createdAt: "2026-05-08T10:00:00Z",
  updatedAt: "2026-05-08T10:00:00Z"
}
```

**日期填写规则**：
- 知道精确日期：选择具体日期，`examDateType` 为 `"exact"`
- 只知道大致月份：选择月份，`examDateType` 为 `"approximate"`，日期存为该月1号
- 展示时：精确日期显示"2026-11-07"，大致月份显示"2026年11月（预计）"

**扩展字段说明**：
- `source`：标记数据来源，方便后续区分手动 vs 自动抓取的数据
- `sourceUrl`：爬虫抓取时记录原始链接，方便用户查看和验证
- `lastSyncAt`：爬虫数据的同步时间，用于判断数据是否过期需要更新

### 存储抽象层

设计一个统一的存储接口，MVP 用本地实现，后续可无缝替换为后端 API：

```javascript
// storage.js - 存储接口定义
const storage = {
  // 用户考试管理
  getExams(),          // 获取所有考试
  getExamById(id),     // 获取单条考试
  addExam(exam),       // 添加考试
  updateExam(id, data),// 更新考试
  deleteExam(id),      // 删除考试
  searchExams(keyword),// 按关键词搜索

  // 预设目录
  getPresetExams(),              // 获取预设考试列表
  searchPresetExams(keyword),    // 搜索预设考试
  getPresetExamById(id),         // 获取单条预设考试

  // 同步（后续扩展）
  syncExams(),         // 从后端同步最新数据
  getLastSyncTime(),   // 获取最后同步时间
}
```

**MVP 实现**：`localStorage.js` — 基于 `wx.setStorageSync`
**后续实现**：`apiStorage.js` — 基于 HTTP 请求调用后端接口

切换时只需替换 `storage` 的引用，业务代码无需改动。
